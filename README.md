# mini-shell

OS课小作业自存档。

## 功能

### 基本框架

- 显示自定义提示符`llynn@mini-shell$`；
- 循环接收用户输入，支持空格分隔（包括连续空格）；
- 输入"exit"时正常退出并释放资源。

### 外部命令执行

- 使用fork()、execvp()和waitpid()执行外部命令
- 支持绝对路径和相对路径的命令调用
- 正确处理僵尸进程

### 内置命令实现

- `cd [路径]`：使用chdir()切换目录；
- `pwd`：使用getcwd()显示当前工作目录；
- `exit`：退出shell。

内置命令直接实现，而非通过exec执行。

### 错误处理

- 至少处理命令未找到、参数错误、权限不足、进程创建失败四类错误，发生时程序不崩溃；
- 提供明确的错误信息。

### 历史命令功能

- 记录最近10条有效命令；
- `history`：显示历史命令列表；
- `!n`：执行第n条历史命令 。

## 使用方式

使用下面的命令编译运行：
```shell
make clean && make
./shell
```
